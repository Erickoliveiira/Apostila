# 📚 REGRAS GERAIS

## 📚REGRAS GERAIS

### <mark style="color:yellow;">REGRAS DA POLICIA</mark> <a href="#regras-da-policia" id="regras-da-policia"></a>

* Qualquer ato de corrupção é proibido.
* É permitido somente o uso de armamento policial. (Não pode usar armamentos ilegais) Está proibido o uso de carros que não sejam VTRs policiais para obter vantagem.
* O uso de armamento deve ser respeitado de acordo com a patente ou unidade.
* Proibido ficar com o ponto aberto, e não estar fazendo o trabalho policial. (Passivo de exoneração e multa)
* Proibido ficar fora da canaleta (DISCORD)

***

### <mark style="color:yellow;">**AÇÕES COM DISPARO DE ARMA DE FOGO**</mark> <a href="#acoes-com-disparo-de-arma-de-fogo" id="acoes-com-disparo-de-arma-de-fogo"></a>

* Disparos de arma de fogo não precisa de mandato.
* Policiais só podem chegar numa ação até o momento que o perímetro for fechado.
* Perímetro deve ser fechado em até 15 minutos após início da ação.
* Não se deve mexer nos corpos até o final da ação.
* Não se deve chamar médico até o final da ação.
* Policial caído não deve voltar pra ação em nenhuma hipótese.
* Após o final da ação os médicos devem priorizar retirar os policiais do local para o HP ou uma zona neutra para realizar as reanimações.
* Caso a polícia perca uma ação aberta contra os bandidos os mesmos devem ir de gg.
* Após isso a prioridade máxima é levantar os bandidos, algemar, e encaminhar para prisão o mais rápido possível.
* Policiais que caíram na ação podem auxiliar no processo de prisão na DP para concluir o mais rápido possível. Após encerrada uma ação contra os bandidos numa favela, ou fac (Invasão) não é passível de investigação pois a ação já terminou e todos foram presos.

### <mark style="color:yellow;">PRISÕES DE ITENS</mark> <a href="#prisoes-de-itens" id="prisoes-de-itens"></a>

{% hint style="success" %}
### **Passível de Apreensão** (itens ilegais) <a href="#passivel-de-apreensao-itens-ilegais" id="passivel-de-apreensao-itens-ilegais"></a>

* Armas (leves e pesadas)
* Drogas
* Munições
* Armas brancas (katana, canivete, soco inglês, etc.)
* Lockpick (somente utilizadas)
* Masterpick
* Dinheiro Sujo (somente apreensão)
* Explosivo (C4, bombas, etc.)
{% endhint %}

{% hint style="danger" %}
### **Proibido Apreender** <a href="#proibido-apreender" id="proibido-apreender"></a>

* Itens de farm como: minérios, componentes químicos, matérias primas para fabricação de farm, etc.
* Ticket de corrida
{% endhint %}

Ou seja, somente itens ilegais que **estejam PRONTOS**. Insumos **são proibidos** de serem apreendidos.
